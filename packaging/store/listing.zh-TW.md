## 2. 說明(Description)

一個常駐在系統列的小工具,自動讓 Windows 剪取工具的「HDR 螢幕擷取色彩校正器」(`IsHDRToneMappingEnabled`)跟著**前景內容實際上是不是 HDR** 保持同步——這樣在 HDR 螢幕上用原生方式截圖,顏色就會正確,不必每次手動去切那個設定。

Windows 的 HDR 是**依 App 各自開關**的,系統沒有提供任何「目前這個視窗是不是 HDR」的 API,你也無從得知目前狀態;把螢幕永久設為 HDR 時,顯示器層級的旗標更是完全不會變。因此本工具改**看實際像素**來判斷:透過 Desktop Duplication 以 scRGB FP16 擷取前景視窗的畫面,檢查是否有足夠的像素超過 SDR 白色(亮部 / 廣色域),藉此分辨 SDR 與 HDR 內容,再據以寫入校正器設定。這是**依內容(像素)判斷,不是看顯示器的 HDR 旗標**;例如一個 SDR 視窗裡播放內嵌的 HDR 影片,也會被正確判為 HDR。若顯示器根本沒開 HDR,校正器就單純維持關閉。

它是**事件驅動**的——在切換視窗或顯示器狀態改變時才重新評估,而非持續輪詢;純黑畫面會被忽略。判斷結果會**逐視窗記住**,並在**剪取工具位於前景時維持不變**,避免它半透明的截圖遮罩在你按下截圖的那一刻反而翻動了設定。無法擷取畫面時(全螢幕獨佔遊戲、受保護內容),會沿用上一次的判斷,而不是亂猜。

**每 App 覆寫。** 少數 App 呈現的 HDR 方式無法從擷取到的像素判斷(取決於該 App 自身的 GPU 呈現,沒有 API 可查)。這時可從系統列選單開啟「應用程式覆寫」對話框,**依程式名稱把特定 App 強制設為 HDR 或 SDR**,跳過像素偵測。

**已知情況。** 有些 App(例如**開啟硬體加速的 Discord**)不論校正器開或關,畫面看起來都不對——關掉時太亮、開啟時太暗——所以任何覆寫都無法修正。請改為**關閉該 App 的硬體加速**,它就會回到單純的 SDR 並正確顯示。

介面提供英文與繁體中文(台灣),依你的 Windows 顯示語言自動選擇。**不需系統管理員權限、不連網、不蒐集任何資料。**

**功能重點**

- 自動讓剪取工具的「HDR 螢幕擷取色彩校正器」跟著前景內容是不是 HDR 同步,截圖顏色就正確。
- 依**實際像素**判斷 HDR(亮部 / 廣色域),不看顯示器的 HDR 旗標;忽略純黑畫面。
- 逐視窗記住 HDR 判斷,剪取工具在前景時維持不變;無法擷取時沿用上次判斷。
- **事件驅動**——依焦點 / HDR 變化反應,而非輪詢。
- **每 App 覆寫**:判斷不出來時,可依程式名把特定 App 強制設為 HDR 或 SDR。
- 常駐系統列;英文與繁體中文(台灣)介面,依 Windows 顯示語言自動選擇。
- **不需系統管理員權限、不連網、不蒐集資料。**
